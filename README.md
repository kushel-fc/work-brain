# work-brain

Kushel's work source of truth — synced daily from Linear, GitHub (`fashioncloud/product-service`, `fashioncloud/brand-data-pipeline`), and Slack (`#brand-data-dev-alerts`).

- **Start here:** [`today.md`](./today.md) — what needs attention today.
- **Zoom out:** [`this-week.md`](./this-week.md) — the week's priority set.
- **Dig in:** `sources/`, `support/`, `prs/`, `shaping/`, `dagster-alerts/` — the current-state detail behind the summaries above.
- **How this repo behaves:** [`CLAUDE.md`](./CLAUDE.md) — structure, conventions, sync rules.

Everything here reflects **current state**, not history. To see what changed, `git log` or `git diff` any file — that's the changelog.

Synced automatically once a day. See `.claude/skills/sync-work-brain/SKILL.md` for the routine, or run `/sync-work-brain` in a session opened on this repo to trigger it manually.
